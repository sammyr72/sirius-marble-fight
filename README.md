# Sirius Marble Fight: website

Static site for Sirius Marble Fight (Baglunch Games), served by GitHub Pages at https://sammyr72.github.io/sirius-marble-fight/

- `index.html`, `styles.css`, `app.js`: the whole site, no build step.
- `STORE_URL` at the top of `app.js`: set it to the Meta Horizon Store page when the game is live and every "Coming to Quest" button turns into a link.
- `img/press/`: downloadable key art and icon.
- The privacy policy lives in its own repo, https://sammyr72.github.io/sirius-marble-fight-privacy/ (that URL is on the store listing, so leave it where it is).
